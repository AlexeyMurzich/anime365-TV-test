# Anime365 Android

Клиент сайта anime365 (smotret-anime) для Android: каталог аниме, просмотр
эпизодов, локальная библиотека и публикация своих переводов.

## Язык

### Каталог

**Аниме**:
Произведение целиком — один тайтл со своими названиями, постером, годом, сезоном и списком эпизодов. Канонический идентификатор — `series` в API.
_Avoid_: сериал, тайтл, шоу, релиз

**Эпизод**:
Одна нумерованная единица аниме: серия, фильм, OVA, спешл или трейлер. Тип эпизода может отличаться от типа аниме.
_Avoid_: серия, выпуск, часть

**Перевод**:
Один готовый к просмотру вариант одного эпизода: конкретный видеофайл с конкретной озвучкой или субтитрами от конкретных авторов. Не текст перевода и не абстрактная «локализация» — это то, что пользователь выбирает и включает. У одного эпизода их может быть сотня.
_Avoid_: озвучка, дорожка, саб, вариант, версия, релиз, видео

**Команда**:
Люди, сделавшие Перевод: группа фансаба или даба либо один автор. В API это `authorsList` и `authorsSummary`; бывает пустой. Не путать со студией, снявшей само аниме.
_Avoid_: авторы, фансаб, даберы, студия

**Вид перевода**:
Озвучка, субтитры или оригинал без перевода — вместе с языком. В API это `type` (`voiceRu`, `subRu`, `raw`, ...), разложенный на `typeKind` и `typeLang`.
_Avoid_: тип, формат, категория

**Источник**:
Откуда взята видеодорожка перевода: телевизионный эфир, Blu-ray, DVD. В API это `qualityType`. Говорит о происхождении записи, а не о её разрешении.
_Avoid_: качество

**Разрешение**:
Размер картинки перевода в пикселях (720p, 1080p, 2160p). Отдельная характеристика от Источника, хотя на сайте оба зовутся «качеством».
_Avoid_: качество, битрейт

**Видеопоток**:
Набор ссылок на видеофайл и файл субтитров конкретного перевода, выдаваемый только по токену и только при активной подписке. Живёт недолго и запрашивается в момент запуска просмотра.
_Avoid_: embed, стрим, ссылка

**Отдельные субтитры**:
Файл субтитров рядом с видео Перевода, который плеер накладывает сам; их можно выключить.
_Avoid_: софтсаб, softsub, внешние субтитры

**Вшитые субтитры**:
Субтитры, впечатанные в картинку Перевода; выключить их нельзя.
_Avoid_: хардсаб, hardsub, встроенные субтитры

### Аккаунт

**Приложение**:
Публичный идентификатор нашего клиента, зарегистрированный на сайте. Не секрет, встраивается в исходный код. В API это `app`.
_Avoid_: клиент, client id, ключ

**Токен доступа**:
Бессрочный секрет, привязанный к одному пользователю, дающий доступ к Видеопотоку и данным аккаунта. В API это `access_token`.
_Avoid_: ключ, сессия, пароль

**Подписка**:
Платный статус аккаунта, без которого Видеопоток не выдаётся. В API это `isPremium` и `premiumUntil`.
_Avoid_: премиум, подписка PRO, тариф

### Библиотека

**Библиотека**:
Личный список аниме пользователя со статусом по каждому. Существует только на устройстве: серверного API для неё нет.
_Avoid_: список, профиль, избранное

**Статус**:
Положение аниме в Библиотеке: смотрю, запланировано, просмотрено, брошено.
_Avoid_: состояние, категория, метка

**Прогресс**:
Сколько пользователь отсмотрел конкретный Эпизод: позиция внутри него и отметка, что он просмотрен. Принадлежит Эпизоду, а не Переводу: смена Перевода Прогресс не сбрасывает.
_Avoid_: позиция, история, watched

**Новый Эпизод**:
Эпизод аниме со Статусом «Смотрю», появившийся после того, как пользователь последний раз открывал это аниме.
_Avoid_: свежая серия, обновление, непросмотренное

### Передача файлов

**Публикация**:
Отправка своего видеофайла и субтитров на сервер с созданием нового Перевода. Направление — от пользователя на сервер.
_Avoid_: загрузка, аплоад, upload

**Скачивание**:
Сохранение видеофайла Перевода на устройство для просмотра без сети. Направление — с сервера пользователю.
_Avoid_: загрузка, download, офлайн-режим

**Онгоинг**:
Аниме, эпизоды которого выходят прямо сейчас. В API это `isAiring`. Отличается от Активного (`isActive`) — тот лишь означает, что запись не скрыта.
_Avoid_: сезонное, текущее, airing

**Лента**:
Готовый серверный срез списка с собственным порядком: недавно добавленные Переводы, Переводы Онгоингов, полный обход по возрастанию `id`. В API это `feed`.
_Avoid_: фид, подборка, поток
