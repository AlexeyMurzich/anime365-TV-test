# Исходный код открыт под GPL-3.0

Раздача через GitHub Releases (ADR 0006) работает только из публичного
репозитория: из приватного пользователь не скачает APK, а проверке обновлений
понадобился бы токен GitHub. Поэтому код открыт. Лицензия — GPL-3.0, а не
MIT или Apache-2.0: она запрещает закрытые форки, например перепакованные с
рекламой или трекерами сборки клиента платного сервиса, и подходит для
F-Droid.

## Следствия

- Каждая зависимость должна быть совместима с GPL-3.0. Apache-2.0, MIT и BSD
  совместимы; Sentry SDK — MIT.
- Идентификатор Приложения (`app`) лежит в коде открыто: документация API
  прямо это разрешает.
- Токен доступа не попадает ни в репозиторий, ни в секреты CI (ADR 0005).
