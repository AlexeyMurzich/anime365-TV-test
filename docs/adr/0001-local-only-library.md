# Библиотека и Прогресс живут только на устройстве

Публичное API anime365 не предоставляет ни списков пользователя
(смотрю / запланировано / просмотрено), ни оценок, ни отметок просмотра:
единственный метод про аккаунт — `GET /api/me`, отдающий только
`isLogined`, `id`, `name`, `isPremium`, `premiumUntil`. Поэтому Библиотека,
Статус и Прогресс хранятся локально в Room, без синхронизации между
устройствами.

## Рассмотренные альтернативы

- **Парсинг HTML страниц сайта** (`/users/profile` и форм изменения статуса).
  Отклонено: ломается от любого редизайна, выходит за границы публичного API,
  требует разбора CSRF-токенов и сессионных cookie параллельно с токеном.
- **Отказ от Библиотеки вовсе.** Отклонено: без «продолжить просмотр» и
  отметки просмотренных эпизодов приложение для сериалов на 28 серий
  непригодно.

## Следствия

- Переустановка приложения или смена устройства теряет Библиотеку. Это нужно
  честно сообщать в интерфейсе, а не делать вид, что данные на сервере.
- Нужен экспорт и импорт Библиотеки файлом — единственный способ переезда.
- Если в API появятся методы списков, локальная база станет кэшем, а не
  источником правды. Схему Room проектируем так, чтобы добавление
  `remoteId` и состояния синхронизации не требовало переписывания.
