# Скачанное хранит Media3, а не Room

Скачивание идёт через `DownloadManager` Media3, и его база закачек — единственное место, где
записано, что скачано. Название аниме, Эпизод и Перевод лежат JSON-ом в самом запросе
(`DownloadRequest.data`), а не в отдельной таблице Room. Это исключение из ADR 0004: там Room —
источник правды для данных сайта.

## Почему

- Состояние, байты и размер закачки всё равно знает только Media3. Таблица в Room дублировала бы
  их и расходилась бы с ними: удалили файл, а строка осталась, и наоборот.
- Скачанное должно играть без сети, даже когда кэш страницы аниме уже стёрт: всё нужное для
  Плеера — в той же записи, что и файл.

## Как устроено

- Видео лежит в `SimpleCache` в `getExternalFilesDir`. Плеер читает его оттуда же через
  `CacheDataSource` по ключу `download:<id Перевода>`, без записи в кэш при обычном просмотре.
- В запросе — ссылка `download[]` без Токена. Токен подставляется в момент запроса для данных с
  этим ключом, поэтому в базе закачек его нет (docs/roadmap.md, M4).
- Отдельные субтитры качаются вторым запросом рядом с видео; в списке Скачанного их не видно.
- Скачанное и база закачек не входят в резервную копию: гигабайты видео не влезут, а база без
  файлов показала бы скачанным то, чего нет.

## Цена

- Скачанное нельзя выбрать SQL-запросом вместе с Библиотекой: экраны склеивают два потока.
- Сменить формат записи — значит читать старые записи: декодер пропускает те, что не разобрал.
