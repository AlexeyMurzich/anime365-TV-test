# Распространение через GitHub Releases, а не через Google Play

Приложение — неофициальный клиент платного стороннего сервиса, и в каталоге
есть контент с `isHentai: 1`. Это независимые поводы для снятия из Google
Play, причём снимают обычно тогда, когда пользователи уже есть. Поэтому
основной канал — GitHub Releases, обновления приложение проверяет само через
GitHub API.

## Следствия

- **Ключ подписи релизов — единственный способ доставить обновление уже
  установленным копиям.** Потеря ключа означает переустановку у всех
  пользователей, а переустановка стирает Библиотеку (см. ADR 0001). Резервная
  копия ключа вне рабочей машины обязательна.
- F-Droid остаётся возможным только при отсутствии проприетарных
  зависимостей — это ограничение на выбор телеметрии и любых SDK.
- Отчёты о сбоях — Sentry: SDK открытый и работает без сервисов Google.
  Только по явному согласию пользователя (по умолчанию выключено), без имени
  пользователя и Токена доступа. Crashlytics отклонён: требует сервисы Google
  и закрывает путь в F-Droid.
