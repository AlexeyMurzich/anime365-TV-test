# Room — единственный источник правды, сеть только пишет в базу

Репозитории всегда отдают `Flow` из Room; слой сети никогда не отдаёт данные
в UI напрямую, он только обновляет базу. UI не знает, откуда пришли данные,
и не содержит ветвления на случай отсутствия сети.

## Рассмотренная альтернатива

**Сеть как источник, база как необязательный кэш.** Отклонено: при
запланированном Скачивании это даёт два поведения на каждом экране — одно
для скачанных эпизодов, другое для всех остальных, — и ветку `if (offline)`
в каждой ViewModel.

## Следствия

- Бесконечные списки (Каталог) проходят через Paging 3 с `RemoteMediator`,
  складывающий страницы в Room. Короткие блоки Главной — Онгоинги, Рейтинг
  сезона, Новые серии — обновляются снимком целиком.
- Кэш данных сайта — отдельный файл `cache.db`, а не общая база с
  Библиотекой. Его можно стереть целиком («Очистить кэш» в Настройках), он
  пересобирается с сервера при смене схемы и исключён из резервной копии
  Android. Цена: Room не делает запросов между базами, поэтому строка
  Библиотеки хранит своё название и постер, а не ссылку на строку кэша.
- Все запросы списков обязаны передавать параметр `fields`: без него каждый
  элемент `/api/translations` тащит внутри полный объект аниме с внешними
  ссылками и описаниями, и база заполняется дублями одного и того же аниме.
- Исключение — Скачанное: его хранит Media3, а не Room (ADR 0010).
