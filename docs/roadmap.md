# Вехи

Каждая веха заканчивается сборкой, которой уже можно пользоваться. Термины —
из [GLOSSARY.md](../GLOSSARY.md), экраны — из [screens.md](screens.md),
решения — из [adr](adr/).

## M0 — Скелет

- Модули по ADR 0002, convention plugins в `build-logic`, version catalog.
- Hilt на KSP, Navigation 3 (ADR 0009), четыре таба-заглушки.
- Тема, сгенерированная из `tokens.json` дизайн-системы Kadr.
- detekt, Spotless с ktlint, Android Lint с baseline, dependency-analysis.
- GitHub Actions на каждый push: `spotlessCheck`, `detekt`, `lint`,
  unit-тесты, debug-сборка.
- Флейворы `dev` и `prod` с разными `applicationId`.

## M1 — Каталог

- `:core:network` (Retrofit, kotlinx.serialization, `fields` в каждом запросе
  списка) и `:core:database` (Room — источник правды, ADR 0004).
- Главная без «Продолжить просмотр», Каталог с поиском и фильтрами, экран
  Аниме.
- Paging 3 с `RemoteMediator`: курсор `afterId` для Лент, `offset` для поиска
  и фильтра.
- Сроки кэша: Онгоинги и Ленты — 15 мин, Переводы Эпизода — 1 ч, Аниме и
  поиск — 24 ч, постеры — 200 МБ на диске.

## M2 — Просмотр

- **Первым делом**: прототип `lib_ass_media` на MP4 с отдельным файлом ASS
  (ADR 0008). Не сработает — фильтр, оставляющий только диалоговые стили.
- Вход через WebView и `/api/accessToken` (ADR 0005), Токен в DataStore,
  зашифрованный ключом Android Keystore. Файл Токена исключить из резервной
  копии Android (`data_extraction_rules.xml`): ключ из Keystore в копию не
  попадает, и восстановленный файл не расшифровать.
- Выбор Перевода, Плеер на Media3 с `MediaSessionService`, PiP, фоновый звук
  (ADR 0008). Видеопоток запрашивается при каждом запуске: ссылки живут
  24 часа (см. [api-notes.md](api-notes.md)).
- Разрешение по умолчанию: 1080p по Wi-Fi, 720p по мобильной сети.
- Прогресс и «Продолжить просмотр».

## M3 — Библиотека

- Статусы, Новые Эпизоды, уведомления раз в 6 часов через WorkManager.
- База Библиотеки входит в резервную копию Android и переживает
  переустановку, если у пользователя включено резервное копирование —
  проверить восстановление на устройстве.
- Экспорт и импорт: JSON с `schemaVersion` через системный выбор файла.
  Внутри — Статусы, Прогресс, запомненные Вид перевода и Команда по каждому
  аниме, ключ — `id` аниме на сайте. Скачанные файлы не входят.

## M4 — Скачивание

- Media3 `DownloadManager`, файлы в `getExternalFilesDir`, по умолчанию
  только Wi-Fi и 720p.
- Источник — ссылка из `download[]`: она не истекает и перенаправляет на
  свежую ссылку CDN. Токен подставляется в момент запроса и в базе закачек
  не хранится.

## M5 — Публикация

- `/api/upload/endpoints`, загрузка по tus с возобновлением,
  `/api/translations/create` с `videoSha256`.
- WorkManager с foreground-уведомлением, ошибки проверки — у полей формы.

## M6 — Первый релиз

- Baseline Profile и Macrobenchmark.
- Sentry, только по согласию (ADR 0006).
- Проверка обновлений через GitHub API.
- Отдельный APK под каждую архитектуру процессора: в сборке нативные
  библиотеки libass.
- Ключ подписи: base64 в секретах GitHub Actions и резервная копия вне
  рабочей машины.
- `versionName` из git-тега (`v1.2.0`), `versionCode` =
  `major·10000 + minor·100 + patch`.

## Когда экран готов

- ViewModel покрыта unit-тестами, основное состояние — скриншот-тестом
  Roborazzi, в том числе с системным шрифтом 200 %.
- Подписи для TalkBack, зона касания не меньше 48dp, контраст по токенам Kadr.
- Ни одной строки текста вне `strings.xml`.
- Проходят detekt, Spotless и Android Lint.

## Тесты против живого API

Только локально, отдельной Gradle-задачей, с Токеном из `secrets.properties`;
без Токена пропускаются. CI проверяет код на записанных ответах сервера через
MockWebServer (ADR 0005).
