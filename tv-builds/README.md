# Anime365 — тестовая сборка для Android TV

Дата: 26 октября 2026 года.

APK: `anime365-tv-debug-armeabi-v7a.apk`
Пакет: `io.github.arenoros.anime365.dev` (devDebug, armeabi-v7a).
Тестовый вариант устанавливается рядом с основной версией.

## Что изменилось

- Добавлена заметная белая рамка фокуса для управления пультом.
- При возврате из карточки аниме или плеера восстанавливается выбранная карточка.
- Основное действие и первый вариант перевода получают начальный фокус.
- При скрытой панели стрелки перематывают видео на 10 секунд; удержание продолжает перемотку.
- Первое OK показывает панель, следующее активирует выделенную кнопку.
- Back сначала скрывает панель, затем закрывает плеер.
- Фокус возвращается после закрытия настроек и выбора перевода.
- Убраны сенсорные ручки окон на TV и исправлено падение при закрытии пустого стека плеера.
